# agentic-ai

AI Brand Visibility & Generative Engine Optimization (GEO) Audit Tool.

Check how ChatGPT, Claude, Gemini, Perplexity, and Grok see your brand. Get an AI Brand Visibility Score and actionable optimization recommendations to improve your AI citations.

## Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/slickyads/agentic-ai)

### Manual deploy

```bash
# Install dependencies
npm install

# Build for production
npm run build

# Preview production build locally
npm run preview
```

## Features

- **AI Brand Visibility Score** - See how often your domain is mentioned across AI platforms
- **Platform Scorecards** - ChatGPT, Claude, Gemini, Perplexity, Grok scores
- **Competitor Analysis** - Who's cited instead of you
- **Source Tracking** - Which websites AI models are reading
- **GEO Action Plan** - Actionable recommendations to improve citations

## Tech Stack

- React 18 + Vite
- Tailwind CSS
- lucide-react icons
